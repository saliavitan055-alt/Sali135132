# קרש קאר (Crash Car) – אתר לקניית רכבים אחרי תאונה

אתר סטטי (HTML/CSS/JS) בעברית. פותחים את `index.html` בדפדפן.

- טופס הצעת מחיר ששולח את הפרטים ישירות לוואטסאפ (054-4411991)
- כפתורי חיוג ווואטסאפ בכל העמוד
- לשינוי טלפון: עורכים את `CONFIG` בראש `script.js`

**לפני העלייה לאוויר:** ההמלצות הן דוגמאות – יש להחליף בהמלצות אמיתיות.

**תמונת רקע:** כרגע יש איור. לתמונה אמיתית של גרר עם רכב פגוע – שמרו אותה בשם `images/hero.jpg` והיא תופיע אוטומטית.

פרסום חינם: GitHub Pages / Netlify / Vercel – פשוט מעלים את התיקייה.

# קל-אשראי – אתר בקשת הלוואות (`loans/`)

אתר סטטי בעברית: מחשבון עם סקאלה (5,000–100,000 ₪, 6–84 חודשים), וטופס בקשה בשלושה שלבים
(פרטים אישיים כולל ת"ז עם בדיקת ספרת ביקורת, כתובת, בנק, צ'קים חוזרים ב-3 שנים אחרונות, חשבון מוגבל).

**לפני העלייה לאוויר:**
- להשלים את פרטי החברה ומספר הרישיון מרשות שוק ההון (מסומנים `[להשלים]` ב-`index.html`). אין לפרסם טענת רישיון בלי רישיון בתוקף.
- להגדיר `CONFIG.submitUrl` ב-`loans/script.js` לשרת HTTPS מאובטח. כל עוד הוא ריק – הטופס במצב הדגמה ולא שולח נתונים.
- להוסיף עמודי תנאי שימוש ומדיניות פרטיות (מידע רגיש – חוק הגנת הפרטיות).
- לעדכן את הריבית להמחשה (`CONFIG.annualRate`) ואת מספר הטלפון.
