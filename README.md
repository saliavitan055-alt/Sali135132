# קרש קאר (Crash Car) – אתר לקניית רכבים אחרי תאונה

אתר סטטי (HTML/CSS/JS) בעברית. פותחים את `index.html` בדפדפן.

- טופס הצעת מחיר ששולח את הפרטים ישירות לוואטסאפ (054-4411991)
- כפתורי חיוג ווואטסאפ בכל העמוד
- לשינוי טלפון: עורכים את `CONFIG` בראש `script.js`

**לפני העלייה לאוויר:** ההמלצות הן דוגמאות – יש להחליף בהמלצות אמיתיות.

**תמונת רקע:** כרגע יש איור. לתמונה אמיתית של גרר עם רכב פגוע – שמרו אותה בשם `images/hero.jpg` והיא תופיע אוטומטית.

פרסום חינם: GitHub Pages / Netlify / Vercel – פשוט מעלים את התיקייה.

# הזמנה דיגיטלית – אפליקציה ליצירת הזמנות לאירועים

נמצאת בתיקייה `invitations/`. פותחים את `invitations/index.html`.

- 8 סוגי אירועים (חתונה, חינה, בר/בת מצווה, ברית, יום הולדת, עסקי ועוד) ו-7 עיצובים, עם תצוגה מקדימה חיה
- יצירת קישור להזמנה ושליחה בוואטסאפ. כל פרטי ההזמנה שמורים בתוך הקישור, אז אין צורך בשרת
- קישור אישי לכל מוזמן עם השם שלו
- עמוד אורח: מעטפה נפתחת, ספירה לאחור, ניווט בוויז ובגוגל מפות, הוספה ליומן, ואישור הגעה בוואטסאפ לטלפון של בעלי האירוע
- רשימת מוזמנים עם מעקב סטטוס וספירת מגיעים (נשמרת בדפדפן שבו היא נוצרה)
- 35 עיצובים עם סינון לפי סוג אירוע, כולל 13 עיצובים מאוירים (פרחי זהב, ארט דקו, הכותל, חופה בירושלים, חינה מרוקאית, פרפרים, חיות היער, בוהו, בלונים, ועיצוב יוקרה מונפש עם כוכב מסתובב ואבק זהב). הציורים נוצרים בקוד (SVG), בלי קבצי תמונה
- 6 אפקטים מונפשים (עלי כותרת, לבבות, קונפטי, נצנצים, בלונים ופתיתים)
- **מנגינות רקע**: 7 מנגינות שנוצרות בדפדפן בלי קבצים (מארש החתונה של ואגנר, הקאנון של פכלבל, אודה לשמחה, יום הולדת שמח, שיר הערש של ברהמס, ושני לחנים מקוריים). אפשר גם להדביק קישור ישיר ל-MP3 משלכם. המנגינה מתחילה כשהאורח פותח את המעטפה, ויש כפתור השתקה
- **תזכורות**: שליחה מסודרת בוואטסאפ, אחד אחרי השני: הזמנה למי שעוד לא קיבל, תזכורת למי שלא ענה, ותזכורת עם ניווט למגיעים לפני האירוע. האפליקציה גם מציעה מתי כדאי לשלוח
- **עדכון אוטומטי של אישורי הגעה** דרך גיליון גוגל בחינם: מדביקים את הקוד מ-`invitations/apps-script.gs` ב-Apps Script, ומחברים לפי ההוראות באפליקציה. אחרי החיבור צריך ליצור את הקישורים מחדש

**חשוב:** כדי שהקישורים יעבדו אצל האורחים, צריך להעלות את האתר לאוויר (למשל GitHub Pages). קישור לקובץ מקומי לא ייפתח במכשיר של מישהו אחר.
